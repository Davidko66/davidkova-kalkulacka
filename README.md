# Davidkova Kalkulačka v1.0

Minimalistická mobile-first PWA pre iPhone a PC. Tri kalkulačky: flip, maximálna nákupná cena, servisná cena. Bez databázy a externých knižníc.

## GitHub Pages
1. Vytvor verejný GitHub repozitár `davidkova-kalkulacka`.
2. Nahraj všetky štyri súbory (`index.html`, `icon.svg`, `manifest.webmanifest`, `sw.js`) do koreňa repozitára.
3. Otvor **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Vyber `main` a `/ (root)`, potom Save.
5. Po nasadení bude stránka na `https://TVOJ-UCET.github.io/davidkova-kalkulacka/`.
6. Na iPhone otvor stránku v Safari → Zdieľať → Pridať na plochu.

## Lokálne spustenie
Na PC otvor `index.html` v prehliadači. Na otestovanie PWA/offline režimu treba HTTPS (napr. GitHub Pages) alebo localhost server.

## Poznámka
Zadané hodnoty sa po obnovení stránky vrátia na príkladové hodnoty. Dáta sa neukladajú. Výsledky sú pred zdanením.
